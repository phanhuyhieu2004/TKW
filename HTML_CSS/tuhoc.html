HTML là viết tắt cho cụm từ Hypertext Markup Language, tạm dịch là ngôn ngữ đánh dấu siêu văn bản tạm dịch là ngôn ngữ đánh dấu siêu văn bản. HTML được sử dụng để tạo và cấu trúc các thành phần trong trang web hoặc ứng dụng, phân chia các đoạn văn, heading, links, blockquotes,… HTML không phải là ngôn ngữ lập trình. Điều này có nghĩa là nó không thể tạo ra các chức năng "động". Hiểu một cách đơn giản hơn, HTML cũng tương tự như phần mềm Microsoft Word, nó chỉ có tác dụng bố cục và định dạng trang web.
